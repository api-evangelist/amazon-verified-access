AWS Verified Access provides secure access to corporate applications without requiring a VPN. It evaluates each application request in real time using security signals like identity, device posture, and contextual data to grant granular access only to users who meet the specified requirements.

**Areas:** Identity and Access Management · AWS · Security · Zero Trust

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
